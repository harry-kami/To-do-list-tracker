Task Tracker 📝
=================

Description:
-------------
A simple CLI program to track tasks. Add, view, update, and delete tasks with status and timestamps.
Tasks are saved in `tasks.json` for persistence.

Features:
---------
- Add new tasks
- View all tasks or filter by status
- Change task status (not done ❌, in progress ⏳, done ✅)
- Delete tasks
- View creation and update timestamps

How to Use:
------------
1. Run the program with Python 3:
   python task_tracker.py

2. Main menu options:
   1 - View all tasks
   2 - Add a task
   3 - View tasks by status
   4 - Edit task status
   5 - Delete a task
   6 - Exit

3. Follow prompts to select tasks or enter descriptions.
4. Tasks are automatically saved and loaded from `tasks.json`.

Stay organized and keep track of your tasks easily!
